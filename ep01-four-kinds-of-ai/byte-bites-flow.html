Walk: one sentence, four brains

Command: python compare.py "Great job, the dosa was cold again."

Step 1
  1. 1
    compare.main

    Joins the words after the script name into one sentence. Because words exist, it calls four_answers, not the scoreboard.

    Created in compare.py:172 · calls four_answers

  2. 2
    rules_label(sentence)

    Splits the sentence into words. RULEBOOK is read suggestion, then praise, then complaint. great matches praise, so it returns praise and never looks at cold.

    Created in a_rules.py:25 · called by four_answers · README recording: praise

  3. 3
    load_and_split()

    load_feedback reads the CSV. clean_text runs on every row. split_feedback hides 10 rows with seed 42. Returns 30 train rows and 10 test rows.

    Created in common.py:72 · called by four_answers

  4. 4
    train_model(...) then predict

    clean_text cleans this one sentence. train_model fits TF-IDF + logistic regression on the 30 training rows. model.predict labels the new sentence.

    train_model created in b_supervised.py:32 · README recording: complaint

  5. 5
    local_embeddings → get_embeddings

    Loads the local MiniLM model once. fit_named_groups calls embed and find_groups on the 30 training sentences, then names each group by its most common human label.

    embed created in c_clusters.py:35 · find_groups at line 44

  6. 6
    embed([sentence]) then kmeans.predict

    The new sentence is turned into numbers and dropped into a group. The README recording prints group 1 (mostly complaint). Those group numbers come from the 30 training rows, so they do not match python c_clusters.py, which groups all 40.

    Called from four_answers, compare.py:162

  7. 7
    classify([sentence])

    build_classifier calls get_llm when no model was passed. get_llm calls get_provider, get_model_name, and check_api_key, then returns a chat client. The chain asks Gemini to fill a FeedbackLabel.

    classify created in d_genai.py:50 · get_llm in llm.py:168

  8. 8
    Print four lines, or the missing-key line

    If the key is missing, four_answers catches MissingAPIKeyError and stores the setup message. The README sample shows that message for D. With a key, D is whatever label and reason the model returns.

    compare.py:164–168
